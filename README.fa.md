# BOTANIC CHEMISTRY

**طبیعت × علم × زندگی روزمره**

[English](README.md) · [فارسی](README.fa.md)

یک فروشگاه مفهومی جوراب با طراحی الهام‌گرفته از مجلات مد، رنگ‌های عاجی، زیتونی و زغالی و نقش‌های ظریف مولکولی. زبان رابط وب‌سایت انگلیسی است. مستندات این مخزن به دو زبان انگلیسی و فارسی نوشته شده‌اند.

## اجرای محلی

برای اجرای وب‌سایت نیازی به نصب وابستگی یا مرحله ساخت نیست. دستور زیر را در پوشه اصلی مخزن اجرا کنید:

</div>

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

<div dir="rtl">

سپس نشانی [http://127.0.0.1:4173](http://127.0.0.1:4173) را در مرورگر باز کنید.

اگر Node.js نصب باشد، میان‌برهای زیر نیز در دسترس هستند:

</div>

```sh
npm run dev
npm run check
```

<div dir="rtl">

دستور `npm run check` فقط صحت نحوی جاوااسکریپت را بررسی می‌کند و جایگزین آزمایش در مرورگر نیست.

## قابلیت‌ها

- تصویر اصلی تمام‌عرض و هویت بصری ظریف با الهام از ساختارهای مولکولی.
- ده مدل جوراب بر اساس برد طراحی ارائه‌شده برای Botanic Chemistry.
- بخش سفارش سریع با انتخاب مدل، انتخاب اجباری سایز، تعداد و نمایش قیمت به‌روز.
- جزئیات محصول، راهنمای سایز و نگهداری، فیلتر مجموعه، جست‌وجو و فهرست علاقه‌مندی‌ها.
- سبد خرید با تغییر تعداد، حذف محصول، محاسبه هزینه ارسال و مرور سفارش.
- ذخیره سبد خرید و علاقه‌مندی‌ها فقط در مرورگر کاربر.
- طراحی واکنش‌گرا برای موبایل و دسکتاپ، پنجره‌های قابل استفاده با صفحه‌کلید و پشتیبانی از کاهش حرکت.

## ساختار پروژه

</div>

```text
dist/
  index.html
  styles.css
  app.js
  assets/
.openai/hosting.json
docs/DESIGN.md
README.md
README.fa.md
```

<div dir="rtl">

فایل `index.html` ساختار صفحه و پنجره‌ها، فایل `styles.css` ظاهر و چیدمان واکنش‌گرا و فایل `app.js` محصولات و رفتارهای خرید را تعریف می‌کند. تصاویر نهایی در پوشه `assets` قرار دارند.

پوشه `dist` را می‌توان روی یک میزبان وب ایستا منتشر کرد. تنظیمات پروژه خصوصی Sites نیز به همین پوشه اشاره می‌کند. این پروژه به فریم‌ورک یا بک‌اند نیاز ندارد.

## محدودیت‌های نسخه نمایشی

این پروژه **فروشگاه مفهومی** است و خرید واقعی انجام نمی‌دهد. قیمت‌ها نمونه و به دلار آمریکا هستند. هزینه ارسال نمونه ۵ دلار است و برای جمع مبلغ محصولات از ۵۰ دلار به بالا، رایگان نمایش داده می‌شود.

درگاه پرداخت، ثبت سفارش واقعی، همگام‌سازی موجودی و ارسال کالا متصل نشده‌اند. صفحه مرور سفارش به‌روشنی اعلام می‌کند که هیچ سفارشی ثبت نشده است.

سبد خرید و علاقه‌مندی‌ها فقط در مرورگر همان کاربر ذخیره می‌شوند. فونت‌های Cormorant Garamond و Montserrat از Google Fonts دریافت می‌شوند. هیچ ابزار تحلیل بازدید یا دسترسی به سرویس‌های متصل پیکربندی نشده است.

تصاویر و برد محصولات برای نمایش مفهومی استفاده شده‌اند. پیش از فروش واقعی، ظاهر محصول، مشخصات پارچه، اندازه‌ها و حقوق استفاده تجاری از تصاویر باید تأیید شوند. توضیحات بیشتر در [یادداشت‌های طراحی و تصاویر](docs/DESIGN.md) آمده است.

## بررسی‌ها

چیدمان در اندازه‌های ۱۴۴۰×۹۰۰ و ۳۹۰×۸۴۴ بررسی شده است. آزمایش‌های دستی مرورگر شامل تغییر مدل، خطای انتخاب‌نکردن سایز، تغییر تعداد، حد ارسال رایگان، ماندگاری سبد خرید، مرور سفارش، جست‌وجو و حالت بدون نتیجه، فیلتر علاقه‌مندی‌ها، منوی موبایل و بستن پنجره‌های تودرتو با کلید Escape بوده‌اند. صحت نحوی جاوااسکریپت و مسیر فایل‌های محلی نیز جداگانه بررسی شده‌اند.
